Tumble Blocks: Tetromino Tower

released

Tumble Blocks is a puzzle game where you stack tetrominoes, clear lines, and create spectacular chain reactions.

Place blocks on a 5×5 board and complete rows or columns. When a line is cleared, the blocks above the lines or unsupported collapse and may complete new lines and more combos.

Create massive chain reactions with a single move!
